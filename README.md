## <img src="https://raw.githubusercontent.com/rosgear/rg-be-config-page/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Расширение модуля «Информация о сайте»

Настройка параметров страниц веб‑приложения RosGear, включая шаблон заголовка, ключевые слова, метаописание и HTML‑разметку.

Расширение модуля входит в состав Панели управления GePanel и cлужит расширением для [модуля «Конфигурация»](https://github.com/rosgear/rg-be-config).

### Установка

Для добавления расширения модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-config-page
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-config-page": "*"
}
```
или скачать архив на [странице расширения модуля](https://rosgear.ru/component/rg-be-config-page/) в каталоге приложений RosGear.

После добавления расширения модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

<a name="english"></a>
## <img src="https://raw.githubusercontent.com/rosgear/rg-be-config-page/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module extension «About the site»

Customize RosGear web application page settings, including title template, keywords, meta description, and HTML markup.

The module extension is part of the GePanel Control Panel and serves as an extension for the [«Configuration» module](https://github.com/rosgear/rg-be-config).

### Installation

To add the module extension to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-config-page
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-config-page": "*"
}
```
or download the archive from the [module extension page](https://rosgear.ru/component/rg-be-config-page/) in the RosGear application catalog.

After adding the module extension to the project, install it into the web application edition using the GePanel Control Panel.
